# 💰 MoneyFlow Personal Finance Dashboard

A modern and interactive personal finance dashboard designed to help users manage their money, track daily transactions, monitor savings, and understand their financial habits through a clean and intuitive interface.

MoneyFlow transforms financial tracking into a simple, organized, and visual experience.

---

## 📸 Overview

MoneyFlow is a personal finance tracking website that provides a centralized dashboard for monitoring income, expenses, available balance, and savings goals.

Built with a modern, responsive interface, MoneyFlow offers both **Light Mode and Dark Mode** to create a comfortable user experience in different lighting environments.

## 🛠️ Tech Stack

MoneyFlow is built using fundamental frontend web technologies without relying on a frontend framework.

| Technology | Purpose |
|---|---|
| **HTML5** | Structures the website and dashboard components. |
| **CSS3** | Handles styling, layouts, responsive design, animations, and theme customization. |
| **JavaScript (Vanilla JS)** | Powers transaction management, financial calculations, interactivity, data persistence, and theme switching. |
| **Chart.js** | Creates interactive financial charts and data visualizations. |
| **LocalStorage API** | Stores transaction data, savings information, and user preferences locally in the browser. |

### Frontend Architecture

- Pure JavaScript without React, Vue, or other frontend frameworks.
- Modular separation between HTML structure, CSS styling, and JavaScript functionality.
- DOM manipulation and event-driven interactions.
- Client-side financial calculations.
- Browser-based data persistence.


### 2. Open the project folder

```bash
cd moneyflow
```

### 3. Run the website

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## ⚠️ Data & Storage

MoneyFlow uses browser LocalStorage to save financial records and preferences.

- Data is stored locally in the browser.
- No backend server or online database is connected.
- Data is not automatically synchronized across different devices or browsers.
- Clearing browser storage may remove saved MoneyFlow data.
